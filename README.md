# KELOMPOK-2---Smart-Hospital-Queue-Record-System
- Priority Queue Poli: Mengelola antrean dengan 3 tingkat prioritas (KRITIS, PRIORITAS, REGULER) menggunakan basis Linked List.
- Stack Riwayat Tindakan: Membangun fitur undo berbasis Stack untuk mencatat log tindakan secara terisolasi bagi masing-masing dokter.
- BST Rekam Medis: Membuat sistem penyimpanan dan pencarian rekam medis historis secara efisien menggunakan nomor rekam medis sebagai kunci.
- Sorting Laporan: Menerapkan algoritma Insertion Sort atau Selection Sort langsung pada Linked List untuk mengurutkan laporan harian pasien yang telah selesai.
- Antarmuka Interaktif (CLI): Membuat menu simulasi Command-Line Interface yang mencakup perintah pendaftaran, pemanggilan pasien, pencarian rekam medis, hingga eksperimen 500 event acak.
